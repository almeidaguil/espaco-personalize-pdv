# Espaco Personalize PDV

Sistema privado, mobile first e PWA para vendas presenciais em eventos, estoque, caixa e relatorios.

## Stack

- Next.js
- TypeScript
- Tailwind
- Supabase
- Zod
- Vitest
- Testing Library
- Playwright
- ESLint
- Prettier
- Husky
- Commitlint
- GitHub Actions
- Vercel
